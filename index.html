Sobre Mí

Soy un entusiasta del desarrollo web con un enfoque principal en el frontend

Apasionado por crear interfaces intuitivas y atractivas. Aunque no cuento con experiencia profesional, he desarrollado múltiples proyectos personales que me han permitido afianzar mis habilidades en tecnologías del lado del cliente y adquirir una sólida base en diseño y desarrollo de interfaces.

Tengo conocimientos básicos en el desarrollo backend, lo que me permite comprender el flujo completo de una aplicación web, así como colaborar en la integración entre frontend y servidor. Además, cuento con experiencia básica-intermedia en electrónica orientada a la robótica, lo que me ha permitido trabajar en proyectos donde combino software y hardware para resolver problemas del mundo real.
Soy autodidacta, curioso por naturaleza y siempre estoy buscando nuevos desafíos que me permitan aprender y crecer como desarrollador.

Proyectos personales

A lo largo de mi aprendizaje he desarrollado diversos proyectos personales que combinan programación, electrónica e innovación. Cada uno de ellos ha sido una oportunidad para aplicar mis conocimientos, resolver problemas reales y seguir mejorando mis habilidades técnicas.

Landing Page para Festival de Música Electrónica

Sitio web responsivo inspirado en el Ultra Music Festival. Incluye secciones de LineUp, galería y precios de entradas. Desarrollado con HTML, CSS, JavaScript, Sass y automatizado con Gulp..

BlogDeCafe

Página tipo blog enfocada en consejos y cursos sobre café. Contiene navegación moderna y diseño limpio ideal para proyectos editoriales o de contenido. Maquetación con HTML y CSS puro.

GuitarSite

Proyecto de tienda online creado con React y manejo de estado mediante Hooks. Incluye un carrito de compras que almacena la información en el localStorage del navegador. Simula una experiencia real de e-commerce con diseño moderno y componentes reutilizables.

Invernadero IOT

Plataforma web para monitoreo y control de un invernadero inteligente, desarrollada con HTML, CSS y JavaScript puro. La interfaz consume rutas HTTP directamente desde un ESP32 que actúa como servidor local, entregando datos en tiempo real de sensores y permitiendo la activación de actuadores conectados al dispositivo. Paralelamente, una API desarrollada en Express.js, desplegada en Docker con Nginx, permite almacenar los datos históricos en una base de datos PostgreSQL y proporciona funciones de autenticación (en desarrollo). Este enfoque permite separar la lógica embebida del hardware con la persistencia de datos y la interfaz de usuario, haciendo el sistema modular y escalable.
